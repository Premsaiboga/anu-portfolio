# Landscape Project Book Viewer

The project detail view is now a landscape two-page book viewer.

- Each project uses its original portfolio page images from `public/assets/pages/`.
- The viewer displays two pages at a time in a landscape spread.
- Left/right arrows and keyboard Left/Right keys turn pages.
- CSS 3D page-turn animation is used for next/previous navigation.
- Page thumbnails allow direct navigation to a spread.
- Zoom, fullscreen, and thumbnail controls are included.
- The source portfolio is not flattened into the web UI; the original page artwork remains the visual source.
- The download buttons use `public/assets/portfolio-landscape.pdf`.

## Landscape download

`public/assets/portfolio-landscape.pdf` is a 27-page A4 landscape PDF. Each PDF page contains two consecutive pages from the original 53-page A4 portrait portfolio side-by-side, producing a landscape book/spread format.
